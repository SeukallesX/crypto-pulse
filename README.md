# CryptoPulse 🚀

A futuristic cryptocurrency dashboard built with React that tracks live market prices, portfolio values, watchlists, trending coins, and Bitcoin candlestick data.

## Features

- Live crypto market data using CoinGecko API
- Searchable Top 10 crypto market table
- Bitcoin 7-day candlestick chart
- Portfolio tracker for BTC, ETH, and SOL
- Watchlist saved with localStorage
- Trending coins section
- Coin detail modal
- Dark and light theme toggle
- Auto-refresh every 30 seconds

## Tech Stack

- React
- Vite
- CoinGecko API
- Recharts
- Lightweight Charts
- CSS
- localStorage
