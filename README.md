# CryptoPulse 🚀

A futuristic cryptocurrency dashboard built with React that provides real-time cryptocurrency market data, portfolio tracking, watchlists, trending coins, and interactive Bitcoin candlestick charts.

CryptoPulse combines modern Web3-inspired design with live blockchain market analytics to create an engaging and responsive cryptocurrency dashboard experience.

---

## ✨ Features

### 📈 Live Crypto Market Data
- Real-time cryptocurrency prices powered by the CoinGecko API
- Automatic market refresh every 30 seconds
- Top cryptocurrency market overview

### 🔍 Search & Discovery
- Search cryptocurrencies instantly
- Filter market results dynamically
- Quick access to trending assets

### 💰 Portfolio Tracker
- Track BTC, ETH, and SOL holdings
- Calculate estimated portfolio value in real time
- Individual asset breakdowns

### ⭐ Watchlist
- Save favorite cryptocurrencies
- Persistent watchlist using localStorage
- Quick access to tracked assets

### 🔥 Trending Coins
- Displays top-performing cryptocurrencies
- Quick access to detailed coin information
- Interactive coin selection

### 📊 Market Analytics
- Bitcoin 7-Day Candlestick Chart
- Live market statistics
- Market capitalization tracking
- Trading volume tracking

### 🪙 Coin Details Modal
- Coin rank
- Current market price
- Market capitalization
- Trading volume
- 24-hour performance

### 🎨 Modern UI
- Dark Mode
- Light Mode
- Glassmorphism-inspired design
- Responsive layout for desktop and mobile devices

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/SeukallesX/crypto-pulse.git
```

Navigate to the project directory:

```bash
cd crypto-pulse
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 🎯 Why I Built This

CryptoPulse was developed as a personal project to explore modern React development, API integration, financial dashboards, and blockchain-related technologies.

The project combines real-time cryptocurrency market data with interactive user interface elements to create a modern Web3-inspired dashboard experience while strengthening skills in frontend development, state management, API consumption, data visualization, and responsive design.
